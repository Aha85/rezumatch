# RezuMatch

פלאגין חינמי ל-Claude שמתאים את קורות החיים שלך למשרה ספציפית, שלב אחרי שלב.

- **ציון ATS משוער** לפני ואחרי, עם מילות המפתח שחסרות לך
- **מאמן, לא טופס:** שאלה אחת בכל פעם, עם אפשרויות ברורות
- **לא ממציא כלום:** כל מספר, תואר וטענה מגיעים ממך, ובדיקה מובנית חוסמת כל דבר אחר
- **קבצים מוכנים לשליחה:** קורות חיים ב-PDF בעמוד אחד, מכתב פנייה תואם, וגרסת Word אם האתר דורש
- **העיצוב שלך:** תבניות נקיות מובנות, או מערכת העיצוב שלך ב-Claude
- **עברית ואנגלית**, כולל תמיכה מלאה מימין לשמאל

**מדריך צעד אחר צעד לכולם: [aha85.github.io/rezumatch](https://aha85.github.io/rezumatch/?lang=he)**

## מה צריך
- Claude: Claude Code, אפליקציית Claude למחשב, או claude.ai
- קורות החיים שלך (PDF, Word, טקסט מודבק או פרופיל לינקדאין), או בלי קורות חיים בכלל: הוא יבנה אותם איתך
- מודעת המשרה (טקסט או קישור)
- כדי שהבדיקות האוטומטיות ויצירת ה-PDF יעבדו במחשב (Claude Code או האפליקציה):
  - Google Chrome או Microsoft Edge (כנראה כבר מותקן אצלך)
  - Python 3 ([python.org/downloads](https://www.python.org/downloads/)). את החבילות הנדרשות Claude מתקין בעצמו, ומודיע לך לפני.

אין Python? זה עדיין עובד: Claude מחשב את הציון ידנית ונותן לך את קורות החיים כדף אינטרנט, שאותו שומרים כ-PDF בשתי לחיצות.

## התקנה

### Claude Code ואפליקציית Claude למחשב
```
/plugin marketplace add Aha85/rezumatch
/plugin install rezumatch@rezumatch
```
אחר כך כותבים `/tailor`, או פשוט "תעזור לי להתאים את קורות החיים למשרה הזו".

### claude.ai
1. מורידים את `resume-tailor.zip` מה-[Release](https://github.com/Aha85/rezumatch/releases/latest) האחרון.
2. ב-claude.ai: Settings, ‏Capabilities, ‏Skills, ‏Upload skill.
3. פותחים שיחה: "תעזור לי להתאים את קורות החיים למשרה הזו".

ב-claude.ai שתי הבדיקות האוטומטיות (המצאת עובדות, שמות קבצים) לא רצות. Claude עדיין עובד לפי אותם כללים.

## פקודות
- `/tailor [קישור למשרה]`: התהליך המלא, מקורות החיים ועד קבצים מוכנים לשליחה
- `/score [קישור למשרה]`: רק הציון המשוער ומה חסר

## פרטיות
הקבצים נשמרים בתיקייה במחשב שלך (ב-Claude Code ובאפליקציה). קורות החיים והתשובות שלך נשלחים ל-Claude כדי לבצע את העבודה, כמו כל הודעה שאת/ה שולח/ת ל-Claude. שום דבר לא נשלח לשום מקום אחר.

## על הציון
הציון הוא הערכה, לפי מילות המפתח במשרה, התאמת התואר, בדיקות פורמט ותוצאות מדידות. מערכות ATS אמיתיות שונות זו מזו, ורובן משאירות את ההחלטה למגייס. משתמשים בציון כדי למצוא פערים, לא כהבטחה.

## אם משהו לא עובד
- **אין PDF או "PDF rendering failed":** מתקינים Chrome או Edge, או פותחים את קובץ ה-HTML ש-Claude נותן, לוחצים Ctrl+P (ב-Mac: Cmd+P) ובוחרים "שמירה כ-PDF".
- **ה-PDF פתוח ואי אפשר להחליף אותו:** סוגרים אותו בתוכנה שבה הוא פתוח. בינתיים Claude שומר עותק עם "(new)" בשם.
- **Claude עוצר ושואל על עובדה:** זו הבדיקה שמונעת המצאות. עונים על השאלה, או מבקשים ממנו להוריד את השורה.
- **משהו אחר:** [פותחים issue](https://github.com/Aha85/rezumatch/issues) ומתארים מה עשית ומה קרה. בבקשה לא לצרף קורות חיים אמיתיים.

## הבהרה
RezuMatch עוזר בניסוח ובעיצוב. הוא לא ייעוץ מקצועי בתחום הקריירה, המשפט או ההגירה. האחריות לוודא שכל מה שכתוב בקורות החיים ובמכתבים נכון היא שלך, לפני ששולחים.
